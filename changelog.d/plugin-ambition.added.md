- **The plugin designs a real job, not a three-step chain** — the authoring skill gains a capability map (every source, data step, decision, model route, medium, MCP server and schedule, each with the example that shows it), a job anatomy (five phases, a depth bar, patterns for state, idempotency, validation, budgets, the always-run report and the single gate, the engine behaviors an author designs around) and a seats-and-images guide, all written into a project by `nika init`. A new job is designed first and deepened with every addition that widens no effect; additions that would (a new send, host, paid model, seat route) are offered in one line. A gate stands only where something leaves the machine or cannot be undone. `/nika:ideas` proposes five workflows from the project, `/nika:capture` turns the conversation's recent work into a checked workflow, both also served as MCP prompts. The intent hint fires on wide jobs (many pages, locales or images, a model comparison, a watcher, a reconciliation) in English and French, and the edit hook judges with the session's own engine build inside the engine tree.
